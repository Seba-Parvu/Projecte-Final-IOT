# Projecte-Final-IOT

L’objectiu principal del projecte és crear un sistema domòtic ambiental intel·ligent basat en una ESP32 capaç de monitoritzar les condicions de l’entorn i actuar automàticament segons els valors detectats. El sistema combina sensors, actuadors i una interfície web per controlar i visualitzar dades en temps real.
El projecte està enfocat a simular un sistema de control ambiental com els que es poden utilitzar en hivernacles, habitacions intel·ligents o espais automatitzats. Per això, es treballa amb sensors de temperatura i llum, així com amb diferents actuadors que permeten reaccionar davant els canvis ambientals.
A més, el sistema incorpora connexió WiFi i una pàgina web accessible des de qualsevol dispositiu de la mateixa xarxa, facilitant la supervisió i el control remot del sistema.
